# Screenshots

The main project README embeds the images from this folder to show the app in action
(since it is not deployed publicly). Drop your PNG files here using the exact names
below and they will appear automatically.

## Images the README expects

| File name | What to capture |
|-----------|-----------------|
| `trending.png` | The Trending page (the default landing page) |
| `scanner.png` | The Scanner page with a ranked token table |
| `watchlist.png` | The Watchlist page (add a token first) |
| `journal.png` | The Trade Journal page |

You can add more and reference them in the README as you like.

## How to capture good screenshots

1. Start the backend, then the frontend (see the root `README.md` "Getting started").
2. Open the app in your browser (Vite prints the URL, usually `http://localhost:5173`).
3. Let a scan run so the tables have data.
4. Capture each page:
   - **Windows:** `Win + Shift + S` (Snipping Tool), or `Win + PrtScn` for full screen.
   - Crop to just the app window so it looks clean.
5. Save as PNG into this folder using the names in the table above.

## Tips for a resume-ready look

- Use a consistent window size for every shot.
- Capture when tables actually have rows (run a scan first).
- If you want to hide personal wallet data, blur or crop it before saving.
- Keep file sizes reasonable (under ~1 MB each) so the repo stays light.
